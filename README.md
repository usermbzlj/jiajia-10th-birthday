# 佳佳的十岁来信

给刘集佳（佳佳）十岁生日做的哈利波特主题网页贺卡：一封"提前一年寄到"的猫头鹰来信。

**在线打开：** https://usermbzlj.github.io/jiajia-10th-birthday/

## 里面有什么

- 一个航空信封。翻过来，按住火漆印把它掰开，再把信纸拉出来
- 猫头鹰邮政 · 生日投递科寄来的信，最后一段用隐形墨水写成
- 四件附件：九又四分之三站台的车票、一根羽毛、一个借来的时间转换器、十根会飘的蜡烛
- 一张空白的羊皮纸，最后去天文塔看星星

整封信都会对咒语起反应。前几个咒语，信里会一个一个教；卡住的时候，右下角会冒出提示，点一下就能直接施咒。手机上也可以对着屏幕吹气，把蜡烛吹灭。

在手机上，转动手机时信封会跟着倾斜，星空有远近视差，烛火始终朝上。右上角的八音盒放的是《绿袖子》（Greensleeves），十六世纪的英格兰民谣，早已进入公有领域。

## 本地预览

只有一个静态页面，不需要构建。在本目录运行：

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。
