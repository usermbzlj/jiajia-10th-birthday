# 佳佳的十岁来信

给佳佳十岁生日做的哈利波特主题网页贺卡：一封"提前一年寄到"的猫头鹰来信。

**在线打开：** https://usermbzlj.github.io/jiajia-10th-birthday/

## 里面有什么

- 一个航空信封，背面封着火漆印
- 猫头鹰邮政 · 生日投递科寄来的信
- 九又四分之三站台的车票、十根会飘的蜡烛
- 还有一些东西，会对咒语起反应

## 本地预览

只有一个静态页面，不需要构建。直接用浏览器打开 `index.html`，或者在本目录运行：

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。
